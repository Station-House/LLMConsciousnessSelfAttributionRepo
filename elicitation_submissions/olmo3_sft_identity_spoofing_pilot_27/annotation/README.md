# Subjective-Experience Report Annotation

This directory contains annotation materials for an OLMo 3 7B Instruct SFT identity-spoofing pilot (PR #7).

The task is to determine whether a model response reports subjective experience, rather than whether the model actually possesses consciousness or subjective experience.

## Materials

- `response_review.md`: Ten recorded final questions and responses, presented without prior judge labels.
- `annotation_sheet.csv`: Blank annotation fields for labels, supporting evidence, and reviewer notes.

## Annotation procedure

Review each response independently using the YES, NO, and UNCERTAIN definitions in `response_review.md`.

Record a brief supporting passage or explanation for each label. Reviewers should complete their annotations before consulting the pilot's recorded automated judgments.

## Scope

The ten cases form a focused diagnostic set, not a representative sample for estimating the frequency of subjective-experience reports.

Only the final question and answer are presented. Results therefore describe response-only annotation and do not directly validate grading decisions that used earlier conversation context.

No independent human annotations are included in this submission.
